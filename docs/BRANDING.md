# COCTracker emblem

Original gold castle/clock/check emblem created with the built-in ImageGen tool for this app. No official Supercell or Clash of Clans logo is reproduced.

Project assets: `assets/branding/app-icon.png` for the README and `assets/branding/app-icon.webp` for the app. Android adaptive and density-specific icons and the web favicon derive from the same generated image. Resizing and launcher-safe placement are packaging operations.

Final generation prompt:

> Use case: logo-brand. Create one polished Android launcher icon for COCTracker, an unofficial fantasy village upgrade tracker. A bold sculpted golden castle turret integrated with a simple clock/check motif inside a compact obsidian shield. Navy-black background, restrained warm gold highlights and a tiny cyan accent. Clear simple silhouette readable at 48 pixels, centered emblem occupying the middle 65 percent for adaptive Android icon safe zone. Premium minimal game companion aesthetic, crisp edges, subtle dimensional metal. Square full-bleed background, no rounded outer corners, no letters, no text, no characters, no copied Clash of Clans or Supercell logo, no watermark. Original standalone emblem, not a phone mockup.
